# vue-composables-toolkit

A robust collection of Vue 3 composition API utilities and helpers.

## Features

- 🔒 **Fully typed** — written in TypeScript with strict mode
- 🌲 **Tree-shakeable** — import only what you need
- ⚡ **Lightweight** — optimized for bundle size
- 🧩 **Vue 3 native** — built purely on the Vue Composition API

## Installation

```bash
npm install @isughra/vue-composables-toolkit
```

## Usage

```typescript
import { useWindowSize } from '@isughra/vue-composables-toolkit';

const { width, height } = useWindowSize();
```
